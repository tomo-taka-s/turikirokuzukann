# 青森釣りアプリ（PWA）

青森県専用の全部入り釣りアプリです。ビルド手順なし・相対パスのみで、GitHub Pages にそのまま置けば動きます。

## フォルダ構成

```
.
├── index.html              # アプリ本体（これ1つで全機能）
├── manifest.webmanifest    # PWAマニフェスト
├── sw.js                   # Service Worker（オフライン対応）
├── .nojekyll               # GitHub Pages用（Jekyll処理を無効化）
├── README.md
└── assets/
    ├── hero.webp           # トップのイラスト
    ├── icon-192.png        # PWAアイコン 192
    ├── icon-512.png        # PWAアイコン 512 / maskable
    └── apple-touch-icon.png # iPhone ホーム画面用 180
```

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（Public）。
2. このフォルダの中身をすべてリポジトリのルートにアップロードします（フォルダごとではなく中身）。
3. リポジトリの **Settings → Pages** を開き、Source を **Deploy from a branch**、Branch を **main / (root)** にして Save。
4. 数分後に表示される URL（`https://ユーザー名.github.io/リポジトリ名/`）を開けばアプリが動きます。

## iPhone にインストール（PWA）

1. Safari で公開URLを開く
2. 共有ボタン → **「ホーム画面に追加」**
3. ホーム画面のアイコンから全画面アプリとして起動できます。一度開けばオフラインでも表示されます。

## 機能

- 今日のコンディション：青森県内8か所（青森港・浅虫・八戸港・大間・むつ・外ヶ浜・深浦・鰺ヶ沢）の天気・風・波（Open-Meteo）、潮の種類と月齢、日の出・日の入り
- 釣果ログ：魚種・サイズ・重さ・ポイント・エサ／ルアー・タックル・メモ、集計と魚種別ランキング
- ポイント：プリセット8か所＋自分のポイント追加、地図リンク
- 魚種図鑑：青森で狙える16魚種（旬つき）＋結び方ガイド5種
- タックル管理：道具リスト、ライン交換などのメンテ目安、持ち物チェックリスト
- 時合タイマー：釣行タイマーとマズメ・潮止まり目安

※ 釣果・ポイント・タックルは、この端末のブラウザ内（localStorage）に保存される想定の設計です。天気の取得には通信が必要です。
